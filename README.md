# Quran Moments Officials — Claude Skill Pack

This ZIP contains a reusable Claude skill for planning original Islamic content for the channel shown in the user's screenshot.

## Included
- `SKILL.md` — main skill instructions.
- `references/channel_profile.md` — channel identity and visual reference notes.
- `references/islamic_accuracy_checklist.md` — publication checks for Quran/hadith claims.
- `templates/shorts_template.md` — repeatable Shorts production template.
- `templates/long_video_template.md` — repeatable long-form video template.
- `templates/metadata_template.md` — title/description/hashtags/keywords template.
- `templates/claude_starter_prompts.md` — ready prompts to use in Claude.

## Install in Claude
1. Extract the ZIP.
2. In Claude, open **Settings / Customize** (the exact labels may vary by Claude plan and interface).
3. If your Claude interface supports Skills, upload the skill folder or ZIP using its Skills upload option. If it asks for a folder, upload the extracted `quran-moments-claude-skill` folder.
4. If Skills are unavailable on your plan, create a Claude Project named `Quran Moments Officials` and paste `SKILL.md` into Project Instructions. Add the reference and template files as Project Knowledge if supported.
5. Start with a prompt from `templates/claude_starter_prompts.md`.

## Important limitations
This package helps Claude generate scripts, scene prompts, metadata, and production plans. It does not by itself generate finished videos, connect to YouTube, or upload videos automatically. Fully automatic creation/upload requires separate tools and account permissions. Review religious references and generated visuals before publishing.
